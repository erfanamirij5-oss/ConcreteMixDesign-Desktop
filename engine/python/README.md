# Python Engineering Engine

این پوشه مغز محاسباتی نرم‌افزار است.

مسئولیت‌ها:

- محاسبات طرح اختلاط بتن
- کنترل استانداردها
- تحلیل دوام و پایایی
- تحلیل دانه‌بندی سنگدانه‌ها
- پیشنهاد اصلاح مصالح و طرح
- تولید خروجی مهندسی قابل توضیح

اصل توسعه:

هر تابع محاسباتی باید تست، ورودی/خروجی مشخص، منبع استاندارد و توضیح مهندسی داشته باشد.

ساختار پیشنهادی فاز بعد:

```text
engine/python
├── pyproject.toml
├── src/tolou_mix_engine
│   ├── mix_design
│   ├── durability
│   ├── aggregates
│   ├── standards
│   ├── reports
│   └── api
└── tests
```
