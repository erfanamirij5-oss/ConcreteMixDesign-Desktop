# ConcreteMixDesign-Desktop

نرم‌افزار جامع طرح اختلاط انواع بتن طلوع، یک نرم‌افزار دسکتاپ ویندوزی برای طراحی، کنترل، تحلیل، مستندسازی و گزارش‌گیری طرح‌های اختلاط بتن است.

## هدف پروژه

این پروژه قرار است یک ابزار صنعتی واقعی برای مهندسان، آزمایشگاه‌ها، واحدهای بتن آماده، مشاوران و طراحان طرح اختلاط باشد؛ نه یک ماشین‌حساب ساده.

تمرکز اصلی:

- طراحی طرح اختلاط انواع بتن بر پایه استانداردها و راهنماهای معتبر
- کنترل دوام و پایایی بر اساس شرایط پروژه و محیط بهره‌برداری
- تحلیل دانه‌بندی سنگدانه‌ها، رسم نمودارها و پیشنهاد اصلاح
- ذخیره کامل پروژه‌ها، مصالح، نتایج، گزارش‌ها و اطلاعات آزمایشگاه
- تولید خروجی حرفه‌ای PDF، چاپ، Excel و مگاپرامپت مهندسی
- آماده‌سازی خروجی نصب ویندوزی `.exe`

## معماری منتخب

- Desktop Shell: Electron
- UI: React + TypeScript
- Engineering Engine: Python
- Local Database: SQLite
- Charts: ECharts
- Reports: HTML/PDF print pipeline
- Packaging: electron-builder + bundled Python engine
