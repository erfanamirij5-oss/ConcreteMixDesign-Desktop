# مدل چندسنگدانه‌ای نرم‌افزار

## هدف

نرم‌افزار باید بتواند در هر طرح اختلاط، تعداد نامحدود سنگدانه با نام و نقش متفاوت ثبت کند؛ مشابه نرم‌افزارهای صنعتی که تعداد ماسه و شن را جداگانه می‌گیرند، اما با انعطاف بیشتر برای پروژه‌های واقعی.

## منطق اصلی

هر سنگدانه یک رکورد مستقل در جدول مصالح است و با نام آزاد توسط کاربر ثبت می‌شود. بنابراین نرم‌افزار محدود به دو گزینه ماسه و شن نیست و می‌تواند ترکیب‌های واقعی زیر را پوشش دهد:

- ماسه طبیعی 0-6
- ماسه شکسته
- ماسه دوبارشور
- ماسه اصلاحی
- شن نخودی
- شن بادامی
- شن 12.5 میلی‌متر
- شن 19 میلی‌متر
- شن 25 میلی‌متر
- سنگدانه بازیافتی
- سنگدانه سبک
- سنگدانه سنگین
- هر نام اختصاصی آزمایشگاه یا کارخانه

## دسته‌بندی پیشنهادی برای فرم مصالح

| فیلد | کاربرد |
| --- | --- |
| نوع کلی مصالح | fine_aggregate یا coarse_aggregate |
| نقش سنگدانه | ماسه، نخودی، بادامی، شن 12.5، شن 19، اصلاحی، خاص |
| نام نمایشی | نام آزاد کاربر برای گزارش و انتخاب در ترکیب |
| منبع | معدن، کارخانه، دپو یا بچ مصالح |
| اندازه اسمی | کنترل استاندارد و انتخاب preset دانه‌بندی |
| وزن مخصوص SSD | محاسبات حجم مطلق |
| جذب آب | اصلاح آب اختلاط |
| رطوبت موجود | اصلاح بچ تولیدی |
| وزن واحد | محاسبات حجمی و کنترل اجرایی |
| درصد شکستگی | کنترل کیفیت سنگدانه درشت و دوام/کارایی |
| وضعیت موجود | خشک، SSD، مرطوب، اشباع سطح خشک نشده |
| دانه‌بندی | درصد عبوری هر الک برای همان منبع |

## جریان کاری کاربر

1. کاربر تعداد نامحدود سنگدانه اضافه می‌کند.
2. برای هر سنگدانه مشخصات فیزیکی و دانه‌بندی وارد می‌شود.
3. نرم‌افزار منحنی هر سنگدانه را جداگانه نشان می‌دهد.
4. کاربر می‌تواند حالت سهم دستی را فعال کند و سهم هر سنگدانه را تغییر دهد.
5. اگر حالت خودکار فعال باشد، موتور ترکیب سنگدانه سهم پیشنهادی را برای نزدیک شدن به محدوده استاندارد محاسبه می‌کند.
6. نرم‌افزار منحنی ترکیبی را با محدوده استاندارد مقایسه می‌کند.
7. خروجی گزارش باید نشان دهد سهم‌ها دستی، پیشنهادی یا نهایی تاییدشده توسط مهندس بوده‌اند.

## رفتار مورد نیاز برای شبیه‌سازی تدین، با ارتقا

در تدین تعداد شن و تعداد ماسه جداگانه وارد می‌شود و جدول دانه‌بندی برای هر منبع تکمیل می‌گردد. در نرم‌افزار طلوع، این مدل باید منعطف‌تر باشد:

- به جای محدود شدن به شمارنده شن/ماسه، هر منبع سنگدانه یک رکورد مستقل دارد.
- گروه‌بندی در UI می‌تواند تعداد ماسه‌ها و شن‌ها را خودکار نمایش دهد.
- کاربر همچنان می‌تواند از دکمه «افزودن ماسه» یا «افزودن شن» استفاده کند.
- نام‌هایی مثل نخودی، بادامی، ماسه شکسته و ماسه طبیعی باید کاملا قابل ثبت و گزارش‌گیری باشند.
- ترکیب نهایی باید بتواند بیش از دو سنگدانه را همزمان تحلیل کند.

## الزامات موتور ترکیب

موتور باید برای هر الک، درصد عبوری ترکیبی را با رابطه زیر محاسبه کند:

```text
combined_passing = sum(material_passing_i * share_i / 100)
```

سپس برای هر الک بررسی شود:

- آیا درصد عبوری ترکیبی بین حد پایین و بالا قرار دارد؟
- کدام سنگدانه باعث خروج از محدوده شده است؟
- افزایش یا کاهش سهم کدام منبع محتمل‌ترین اصلاح است؟
- آیا جمع سهم‌ها 100 درصد است؟

## وضعیت پیاده‌سازی

- ثبت چند مصالح با نام آزاد در معماری فعلی پشتیبانی می‌شود.
- حالت سهم دستی سنگدانه‌ها و ذخیره سهم‌ها اضافه شده است.
- مرحله بعد باید فیلدهای تخصصی سنگدانه، گروه‌بندی UI و موتور ترکیب خودکار اضافه شود.
