# ACI CODE-318-25 — Source Evidence Record

## Authority
American Concrete Institute (ACI), Committee 318.

## Exact edition identity
- Designation: ACI CODE-318-25
- Publication year: 2025
- Title: *Building Code for Structural Concrete—Code Requirements and Commentary*
- Pages shown by ACI: 702
- ACI public abstract/product metadata states that durability is within the Code scope.

## Public-source evidence captured for G02B
The official ACI public pages establish:
- ACI CODE-318-25 is the current 2025 edition identified by ACI;
- the Code provides minimum requirements for structural concrete materials, design and detailing;
- durability is explicitly within the scope of design and construction requirements;
- the public table of contents exposes the code organization and durability references at a structural level.

## Evidence boundary
Public ACI metadata is sufficient to establish document identity, edition, authority and general scope. It is not treated as sufficient evidence for certifying the exact numerical/category content currently embedded in Tolou's durability engine.

Until an authorized exact-edition source is reviewed, the following remain unverified:
- F/S/W/C exposure classification thresholds and applicability notes;
- maximum w/cm values;
- minimum strength requirements;
- target air values and NMSA policy;
- chloride limits;
- sulfate cementitious restrictions and exceptions;
- any code commentary/exception that changes applicability.

## Copyright handling
Tolou records identity, rule keys and compact source locators/evidence state. It does not commit the copyrighted ACI code text or tables wholesale.

G02B may add provenance, verification-state guards, deterministic engineering-core tests and fail-closed protections without claiming standards-derived numerical compliance. A rule can be promoted to `verified_exact_edition` only after authorized evidence and independent tests are recorded.
