# چک‌لیست اعتبارسنجی build

## هدف

این فایل مشخص می‌کند هر نسخه قبل از ادامه توسعه باید چه کنترل‌هایی را پاس کند.

## کنترل‌های فاز فعلی

### 1. نصب وابستگی‌ها

```bash
npm install
```

### 2. کنترل TypeScript

```bash
npm run typecheck
```

### 3. تست موتور Python

```bash
cd engine/python
python -m pip install -e .[dev]
python -m pytest
```

### 4. build برنامه

```bash
npm run build
```

### 5. اجرای برنامه توسعه

```bash
npm run dev:ui
npm run dev:electron
```

### 6. تست دستی داخل برنامه

- برنامه باز شود.
- داشبورد نمایش داده شود.
- دکمه «تست موتور Python» کار کند.
- خروجی نمونه شامل آب، مواد سیمانی و w/cm نمایش داده شود.
- اگر Python در دسترس نیست، خطای قابل فهم نمایش داده شود.

## کنترل قبل از انتشار صنعتی

- Python Engine همراه برنامه bundle شود.
- دیتابیس در مسیر امن userData ساخته شود.
- خروجی PDF تست شود.
- فایل نصب Windows روی سیستم تمیز نصب و اجرا شود.
- نسخه موتور محاسبات و استانداردها در خروجی گزارش ثبت شود.
