# توکن‌های طراحی UI بر اساس قالب طلوع

این نرم‌افزار باید از زبان بصری خانواده طلوع استفاده کند.

## اصول ظاهری

- زبان فارسی و راست‌به‌چپ
- هدر سرمه‌ای با خط نارنجی
- کارت‌های KPI برای وضعیت سریع
- سایدبار ساختاریافته
- پنل‌های مهندسی با جدول و نمودار
- حالت روشن/تاریک
- خروجی چاپی رسمی با برند آزمایشگاه و طلوع
