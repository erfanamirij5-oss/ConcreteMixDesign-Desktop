# سیاست کیفیت مهندسی نرم‌افزار

این نرم‌افزار برای استفاده صنعتی طراحی می‌شود؛ بنابراین کیفیت فقط ظاهر زیبا نیست.

## اصول

1. هر محاسبه باید قابل تست باشد.
2. هر عدد خروجی باید منبع یا فرضیه داشته باشد.
3. هر هشدار دوام باید در گزارش نهایی قابل مشاهده باشد.
4. اگر داده ناکافی باشد، نرم‌افزار باید اعلام کند و نتیجه قطعی ندهد.
5. کاربر باید بتواند طرح را بعداً باز کند و دقیقاً همان خروجی را ببیند.
6. نسخه استانداردها و موتور محاسبه باید ذخیره شود.
7. خروجی PDF باید رسمی، خوانا و قابل ارائه به پروژه باشد.

## تست‌های ضروری

- تست محاسبات ACI 211.1
- تست اصلاح رطوبت و جذب سنگدانه
- تست کنترل دانه‌بندی
- تست کنترل دوام
- تست ذخیره و بازیابی پروژه
- تست تولید گزارش PDF
- تست خطاهای ورودی ناقص

## مرز مسئولیت

نرم‌افزار ابزار کمک‌مهندسی است. تصمیم نهایی پروژه باید توسط مهندس مسئول، آزمایشگاه و الزامات قراردادی/آیین‌نامه‌ای تأیید شود.
