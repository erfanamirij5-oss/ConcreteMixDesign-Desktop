# معماری نرم‌افزار جامع طرح اختلاط بتن طلوع

## تصمیم معماری

این پروژه از ابتدا با معماری دو‌موتوره ساخته می‌شود:

1. **Electron + React + TypeScript** برای نرم‌افزار دسکتاپ، داشبورد، فرم‌ها، گزارش، نمودار و تجربه کاربری.
2. **Python Engineering Engine** برای محاسبات مهندسی، کنترل استانداردها، تحلیل دانه‌بندی، دوام، پیشنهاد اصلاح و توسعه الگوریتم‌های پیشرفته.

این تصمیم باعث می‌شود نرم‌افزار هم ظاهر صنعتی و نصبی ویندوزی داشته باشد، هم مغز محاسباتی آن مستقل، قابل تست و قابل توسعه بماند.

## لایه‌ها

### 1. Desktop Layer

مسئول:

- اجرای برنامه روی ویندوز
- ساخت فایل نصب `.exe`
- مدیریت پنجره‌ها
- ارتباط امن بین UI و موتور Python
- دسترسی کنترل‌شده به فایل‌ها و دیتابیس

تکنولوژی: Electron

### 2. User Interface Layer

مسئول:

- داشبورد مدیریتی
- فرم‌های پروژه، آزمایشگاه، مصالح و طرح اختلاط
- نمودارها
- راهنماها و FAQ
- نمایش هشدارهای مهندسی
- خروجی چاپ و PDF

تکنولوژی: React + TypeScript

### 3. Engineering Engine Layer

مسئول:

- محاسبات طرح اختلاط
- کنترل نسبت آب به مواد سیمانی
- کنترل مقاومت هدف
- کنترل دوام و پایایی
- تحلیل دانه‌بندی سنگدانه‌ها
- پیشنهاد اصلاح مصالح
- تولید خروجی مهندسی قابل توضیح

تکنولوژی: Python

### 4. Data Layer

مسئول:

- ذخیره پروژه‌ها
- ذخیره اطلاعات آزمایشگاه و طراح
- ذخیره مصالح، منحنی دانه‌بندی، نتایج و گزارش‌ها
- نگهداری نسخه محاسبه و استاندارد مرجع

تکنولوژی: SQLite

## اصل مهم صنعتی

هر خروجی مهندسی باید دارای این موارد باشد:

- روش محاسبه
- استاندارد یا راهنمای مرجع
- فرضیات ورودی
- محدودیت‌ها
- هشدارهای کاربردی
- وضعیت قبول/رد/نیاز به بررسی

هیچ عدد مهندسی نباید بدون منبع، فرضیه و قابلیت ردیابی تولید شود.
